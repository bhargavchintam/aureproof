Aureproof

Evidence you can check
for AI agent evals

Open source. Signed, re-scorable results, and a gate that can say “inconclusive”.

Bindu Bhargava R Chintam · solo founder · github.com/bhargavchintam/aureproof

The problem

Agent eval results are hard to trust

01

Broken graders still count

OpenAI found 59.4% of 138 audited SWE-bench Verified tasks flawed.

02

Runs can’t be re-checked

Scores travel as a number. Nobody outside can confirm how it was made.

03

Luck gets called a win

A fixed threshold can’t say “too close to call”.

Source: OpenAI, “Why SWE-bench Verified no longer measures frontier coding capabilities”, Feb 2026

The solution

Three checks,
end to end

Health record. A task counts only if its grader passes controls.
Signed bundle. Anyone can verify and re-score the run offline.
Fixed gate. Pass, fail or inconclusive, with rules set before the run.

This is Aureproof,
evidence you can check for AI agent evaluations.
When a team says its agent got better,
nobody outside the team can check that claim.
The grader might be broken,
the run can't be re-checked,
and a lucky result gets called a win.
Aureproof adds three checks.
It proves each task's grader works.
It seals the run into a signed bundle.
And it uses a gate
that is allowed to say,
inconclusive.
Here is a real Claude Code run.
Its signature verifies offline against
the signing workflow on main.
It re-scores to the same
numbers with no API key.
The agent found all three planted bugs,
but only three of its
12 findings were real.
Recall alone would call that perfect.
